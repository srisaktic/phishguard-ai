Full Steps to Run After Clone
Step 1 — Create a Python virtual environment
cd "/Users/sri/Desktop/Deploy project files/phishguard-ai-main"
python3 -m venv venv
source venv/bin/activate

Step 2 — Install Python dependencies
This takes 5-10 minutes — it downloads torch, transformers etc.
pip install -r requirements.txt

Step 3 — Start the backend (Terminal 1)
source venv/bin/activate
python run_backend.py
Wait until you see:
[self-test] phishing email → 1.000 ✓
Uvicorn running on http://0.0.0.0:7860

If the port value is different..got to frontend--> vite.config -->change new port number


Step 4 — Install frontend dependencies (Terminal 2, first time only)
cd "/Users/sri/Desktop/Deploy project files/phishguard-ai-main/frontend"
npm install

Step 5 — Start the frontend (same Terminal 2)
npm run dev

Step 6 — Open the app
Go to http://localhost:5173 in your browser.
